# 🛡 AI Email Spam Detector

AI Email Spam Detector is a Machine Learning based web application designed to detect whether an email or message is **Spam** or **Ham (Not Spam)**.

The system uses Natural Language Processing (NLP) techniques and a Machine Learning model to analyze message content and identify suspicious emails.

## Features

✔ Spam and Ham email classification  
✔ Machine Learning based prediction  
✔ TF-IDF text analysis  
✔ Spam probability score  
✔ Suspicious keyword detection  
✔ Simple and user-friendly interface  

## Technologies Used

* Python
* Flask
* Scikit-learn
* Pandas
* Natural Language Processing (NLP)
* HTML5
* CSS3
* JavaScript

## Machine Learning Model

* Algorithm: Multinomial Naive Bayes
* Feature Extraction: TF-IDF Vectorization
